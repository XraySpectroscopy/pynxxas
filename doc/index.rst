pynxxas |version|
=================

Library for reading and writing XAS data in `NeXus format <https://www.nexusformat.org/>`_.

- :myhdf5:`As XANES ESRF (transmission + reference + multi-detector fluorescence) <manual/BlissMultiModal/converted.nx>`
